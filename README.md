# Offline Portfolio - Progressive Web App

## Project Description
This project is a personal portfolio website developed as a Progressive Web Application (PWA). It allows users to install the portfolio on their devices and access important pages even without an internet connection.

## Technologies Used
- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)
- Service Worker
- Cache API

## Features
1. Installable Web Application.
2. Web App Manifest.
3. Offline support.
4. Service Worker registration.
5. HTML, CSS and JavaScript caching.
6. Offline fallback page.
7. Responsive design.
8. Works on desktop and mobile browsers.

## Project Structure
- index.html: Home page.
- about.html: About page.
- projects.html: Projects page.
- contact.html: Contact page.
- offline.html: Offline fallback page.
- css/style.css: Website styling.
- js/app.js: JavaScript functionality.
- manifest.json: PWA installation settings.
- service-worker.js: Offline caching functionality.
- icons/: Application icons.

## How to Run
1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select Open with Live Server.
5. Open Chrome Developer Tools.
6. Go to Application → Service Workers.
7. Check whether the Service Worker is activated.
8. Open the Network tab and enable Offline to test offline functionality.

## Objective
To develop an installable portfolio website that provides offline access to its core pages using Progressive Web Application technology.
